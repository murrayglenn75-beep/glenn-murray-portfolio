# Project image assets

This directory holds real, reviewed image assets used by portfolio case studies. It intentionally contains no placeholder images.

## Activation rules

- Store each project’s approved images in a project-specific subdirectory, for example `public/images/projects/signet/cover.png`.
- Use only files that are ready for public distribution and accurately represent the named project.
- Add the file path and its descriptive alt text to the project frontmatter only after the image exists in this directory.
- The portfolio ignores a media declaration unless its local file exists and it has alt text. This keeps incomplete references inactive.
- Do not add invented screens, synthetic diagrams presented as product artefacts, logos without permission, or sensitive customer information.

See `docs/project-image-checklist.md` for the full review checklist and frontmatter field reference.
